This dashboard tracks how complete the Site Master Data is for each site. Site Master Data is the central collection of information about a site, covering general details, key contacts, maturity assessments, and OT application counts. Each column represents a section; hover the ⓘ button next to a column header to see which fields are included. Completion bars go from red (empty) to green (fully filled). Click column headers to sort.

Review Status is independent of completion. It indicates whether the Site Data Admin or Digital SPOC has recently reviewed the information. The goal is to have every site's data reviewed at least once per quarter. Only the assigned Site Data Admin or Digital SPOC can edit a site's data (pencil icon on the left).
