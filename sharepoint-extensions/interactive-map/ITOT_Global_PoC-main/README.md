# ITOT Global PoC

SPFx Bing Maps web parts for the ITOT Community Hub.

- **Healthcare map** — sites from Site Master Data (Healthcare sector)
- **Predictive Maintenance map** — items from the Predictive Maintenance list, coordinates from Site Master Data, pins colored by Sector (Life Science, Healthcare, Electronics)
